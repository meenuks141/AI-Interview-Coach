# AI Interview Coach

An interactive AI-powered technical interview simulator built using Python, Streamlit, and Google’s Gemini API.

AI Interview Coach helps candidates practice technical interviews by generating dynamic questions, evaluating answers, calculating performance scores, and providing personalized improvement recommendations.

## Features

* Role Selection: Choose from six technical roles.
* Difficulty Selection: Beginner, Intermediate, and Advanced.
* Dynamic Interview Questions: Gemini generates role-specific questions.
* AI Answer Evaluation: Evaluates correctness, depth, and clarity.
* Conversation Management: Maintains interview progress using Streamlit Session State.
* Deterministic Scoring: Calculates final scores using Python.
* Performance Report: Generates strengths, weaknesses, and a seven-day improvement plan.
* Report Download: Download interview results in JSON format.

## Installation and Setup

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL
cd AI-Interview-Coach

2. Create a virtual environment

python -m venv .venv

Activate it:

Mac/Linux:

source .venv/bin/activate

Windows:

.venv\Scripts\activate

3. Install dependencies

pip install -r requirements.txt

4. Configure Gemini API

Create a .env file in the project directory.

Add:

GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-2.5-flash

Replace the API key with your own key from Google AI Studio.

Never upload your actual API key to GitHub.

5. Run the application

streamlit run app.py

The application will open in your browser.

## How It Works

Step 1: Interview Configuration

The candidate selects a technical role and difficulty level.

Step 2: Question Generation

Gemini dynamically generates interview questions based on the selected role and difficulty.

Step 3: Answer Evaluation

Each answer is evaluated using three criteria:

* Correctness
* Depth
* Clarity

Gemini returns structured JSON containing ratings, feedback, strengths, and improvements.

Step 4: Deterministic Scoring

Python calculates the final score using a weighted scoring formula:

final_score = (
    avg_correctness * 0.40
    + avg_depth * 0.35
    + avg_clarity * 0.25
) / 5 * 100

The final score is calculated independently of the LLM.

Step 5: Performance Report

After completing five questions, the application generates a report containing:

* Overall assessment
* Key strengths
* Weaknesses and areas to improve
* Technical knowledge assessment
* Seven-day improvement plan
* Interview readiness

Step 6: Download Results

Candidates can download their complete interview history, evaluations, and final report as a JSON file.

## Obstacle Log

During development, several challenges were encountered:

1. Gemini API Integration: Configured the Google GenAI SDK and environment variables.
2. API Rate Limits: Encountered 429 RESOURCE_EXHAUSTED errors during testing. Optimized API usage and continued testing when quota was available.
3. JSON Parsing: Implemented regular expressions to extract structured JSON responses.
4. Session Management: Used Streamlit Session State to preserve interview progress.
5. Consistent Scoring: Implemented deterministic weighted scoring using Python.
6. Performance Reporting: Maintained interview history to generate comprehensive reports.
